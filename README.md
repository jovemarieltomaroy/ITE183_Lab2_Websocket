
# ITE183 Laboratory 2: WebSocket Server

## Description

This project implements a real-time WebSocket chat server
using Bonezegei Scripting Language (BSL) v1.3.3.

The application allows multiple browser clients to
communicate through WebSocket broadcasting.

## Features

- HTTP server using Bonezegei
- WebSocket client connections
- Real-time multi-client message broadcasting
- Client connection and disconnection tracking
- Custom 404 error page
- Browser-based chat interface

## Technologies Used

- Bonezegei Scripting Language v1.3.3
- HTML
- CSS
- JavaScript
- GitHub Codespaces

## Installation

1. Install Bonezegei v1.3.3.
2. Clone the repository.
3. Open the project directory.
4. Run `bzg install`.
5. Run `bzg run`.
6. Open the application on port 8000.

## Testing

Open the application in two browser windows.

Send a message from one window and verify that
the message is received by both connected clients.

Visit an undefined URL path to test the custom 404 page.
